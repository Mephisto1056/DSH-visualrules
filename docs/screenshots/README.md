Real UI captures are intentionally not mocked or re-drawn. To add them:

1. Open a repository with a `.dsh/profile.yaml` that exercises identity, environment, protected branches, and a pack.
2. Capture the **session header + right-sidebar quick preview** at a normal desktop width.
3. Capture **Workspace → Validation** with a blocked event and the Git hook card.
4. Capture **Workspace → Rule packs** and **Injection preview**.
5. Save as PNG at 2× and reference them from `README.md` / `README_ZH.md` with descriptive alt text.

Do not present a hand-built HTML replica as a screenshot of the plugin.
